# Privacy Policy

## Data Collection

This plugin collects the following data when in use:

- **API Key**: Your WattCloud API key, used to authenticate requests to the
  WattCloud API.

## Data Usage

- The API key is used solely to authenticate requests between the Dify instance
  and WattCloud's API.
- No other user data is collected or stored by this plugin.
- Prompt content and model responses are transmitted to WattCloud's API for
  processing, subject to WattCloud's privacy policy.

## Data Storage

- The API key is stored encrypted within the Dify platform.
- No data is stored locally by the plugin itself.

## Contact

For privacy inquiries, contact: support@watt-cloud.com
