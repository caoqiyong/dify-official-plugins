## Overview

WattCloud is an AI model platform that provides access to various
large language models (DeepSeek, GLM, Kimi, MiniMax, Qwen3.5 and more)
through a unified OpenAI-compatible API.

## Configure

Install the WattCloud plugin, then configure it by entering your API Key.
Get your API Key from [WattCloud](https://www.watt-cloud.com/).
